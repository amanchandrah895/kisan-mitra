# Converting nutrient recommendations into fertilizer quantities

Fertilizer recommendations are given as kilograms of nutrient per hectare in the order N : P2O5 : K2O (for example 120:60:30). Farmers buy fertilizer products, so the nutrient amount must be converted to product weight.

## Nutrient content of common fertilizers
- Urea contains 46% nitrogen (N).
- Single super phosphate (SSP) contains 16% phosphorus as P2O5.
- Muriate of potash (MOP) contains 60% potassium as K2O.

## Formula
Product needed (kg) = nutrient recommended (kg) x 100 / nutrient percentage in the product.
- Urea (kg) = N x 100 / 46, which is about N x 2.17.
- SSP (kg) = P2O5 x 100 / 16, which is P2O5 x 6.25.
- MOP (kg) = K2O x 100 / 60, which is about K2O x 1.67.

## Worked example: timely sown irrigated wheat (120:60:30 per hectare)
Urea = 120 x 100 / 46 = about 260 kg; SSP = 60 x 100 / 16 = 375 kg; MOP = 30 x 100 / 60 = 50 kg per hectare. These match the published table for wheat (urea 260 kg, SSP 375 kg, MOP 50 kg).

## Area conversion
1 hectare = 2.471 acres, and 1 acre = 0.4047 hectare. To get the quantity for an acre, multiply the per-hectare quantity by 0.4047.

## Practical notes
Split nitrogen as recommended for the crop rather than applying it all at once. Soil-test based recommendations from the Soil Health Card should be preferred over blanket doses.
